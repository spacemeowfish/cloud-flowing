# 员工请假制度（演示版）

本制度仅用于本地知识库功能演示。正式员工每个自然年度享有十个工作日带薪年假。入职未满一年的员工按照当年度实际在岗月份折算，折算结果不足半天的部分不计。年假原则上应在当年使用，确因项目安排无法休完时，经部门负责人和人力资源确认后，最多可结转五天至下一年度第一季度。

员工每年可申请五个工作日带薪病假。连续病假超过一天时，应在返岗后三个工作日内补充正规医疗机构出具的就诊材料。事假不带薪，单次不宜超过三个工作日。婚假、产假、陪产假和丧假按照所在地适用政策以及公司当期制度执行，本演示文档不提供具体天数。

请假应先在任务系统中提交，半天以内由直属主管审批；超过半天且不超过三天，由直属主管和部门负责人审批；超过三天还需要人力资源复核。紧急情况下可先通过电话或消息告知主管，并在返岗后一个工作日内补单。未经批准擅自离岗不视为已请假。员工查询剩余年假时，应以任务系统显示的实时余额为准。
