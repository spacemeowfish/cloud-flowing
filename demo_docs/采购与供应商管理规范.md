# 采购与供应商管理规范（演示版）

本规范仅用于行政流程演示。采购需求由使用部门提出并填写需求说明，明确品名、规格、数量、期望到货时间和预算范围。单项采购金额低于两千元时由部门负责人审批；两千元至五万元由采购管理部门组织比价或询价；超过五万元的采购按招采流程执行。任何采购都应保留比价记录、审批单据和验收凭证，做到全过程可追溯。

供应商应通过资质审查后进入合格供应商名录，审查内容包括营业执照、相关资质、质量记录和必要的安全合规说明。涉及数据处理的外包服务，应在合同中明确数据归属、处理范围、保密义务和违约条款，并评估供应商的数据保护能力。供应商不得被授权直接访问公司内部系统，需访问时应使用受限账号并设定有效期。

到货后由使用部门和采购管理部门共同验收，核对数量、规格和外观，并在验收单上签字。验收不合格的货物应在规定期限内退回或换货。供应商履约情况每半年评估一次，评估结果影响后续合作。员工不得收受供应商可能影响公正判断的礼品或利益，发现利益关联时应主动申报回避。
