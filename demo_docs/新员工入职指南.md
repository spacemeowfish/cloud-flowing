# 新员工入职指南（演示版）

本指南描述虚构公司的演示流程。新员工第一天应先在接待处完成身份核验和入职签到，再由人力资源介绍办公区域、安全出口、考勤规则和基础制度。上午通常完成合同材料确认、组织通讯录开通和门禁领取。任何证件复印件都应通过指定渠道提交，不要发送到个人聊天账号。

办公电脑由 IT 服务台根据入职工单发放。员工领取时应核对资产标签、配件清单和外观状态，并在资产确认单上签收。默认软件由设备管理系统安装，确需新增开发或设计软件时，通过软件申请流程说明用途和授权来源，不得自行安装来源不明的破解程序。电脑领取问题可联系入职工单中的 IT 负责人，不使用固定个人姓名。

部门会在入职当天分配一名导师，导师负责介绍团队协作方式、代码或文档规范以及首月目标。员工应在第一周完成安全培训、数据分级测验和必要的业务课程，并与直属主管确认三十天学习计划。系统权限按照岗位最小权限开通；缺少权限时通过工单申请，不借用他人账号处理任务。
