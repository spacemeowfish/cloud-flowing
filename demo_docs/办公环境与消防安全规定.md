# 办公环境与消防安全规定（演示版）

本规定用于模拟办公管理知识库。办公区域应保持通道畅通，不得在消防通道、安全出口和配电箱前堆放物品。员工应熟悉所在楼层的疏散路线和集合点，消防演练按行政通知参加。发现设备冒烟、焦糊气味或漏水等异常时，应立即报告行政支持并远离危险区域，不要自行处理电气故障。

工位区域应保持整洁，电源插座不超负荷使用，不私拉乱接电线。充电设备使用完毕后应及时拔除，不得在无人看管时长时间充电。易燃物品应存放在指定区域，禁止在办公区域使用明火或大功率非标准电器。下班离开时关闭个人电脑、显示器电源和桌面用电设备。

访客进入办公区域应在前台登记并由接待人陪同，不在敏感区域停留或拍照。废弃纸质材料含敏感信息的，应投入碎纸箱统一销毁，不得随意丢弃。涉及客户资料或未公开项目内容的打印件，用毕后应及时取走或放入保密文件柜。发现安全隐患可通过行政服务平台提交，行政支持应在两个工作日内反馈处理安排。
