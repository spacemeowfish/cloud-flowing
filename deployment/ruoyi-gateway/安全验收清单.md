## 2. 端口收敛：防火墙仅放行 443，其余服务外网不可达

验证方法（在**外网设备**上执行）：

```bash
# 以下都应"连接失败/超时"（不通）；只有 443 通
telnet <IP> 22      # SSH 不通（或只有内网能通）
telnet <IP> 8080    # 若依后端不通
telnet <IP> 8000    # FastAPI 不通
telnet <IP> 3306    # MySQL 不通
telnet <IP> 6379    # Redis 不通
telnet <IP> 443     # 通（出现黑屏/字符流即通）
```

板子上执行（确认只监听回环）：

```bash
sudo netstat -tlnp | grep -E ':(8080|8000|3306|6379)'   # 期望：全绑定 127.0.0.1
sudo ufw status                                          # 期望：443 (和 22 内网) 放行，其余 deny
```

## 5. 闸机纵深：绕过 Nginx 直连 FastAPI 端口，无有效 token 仍全部 401

验证方法（在**板子上**执行，模拟攻击者已进入内网）：

```bash
curl -s http://127.0.0.1:8000/health                      # 期望 200（唯一白名单）
curl -s -w '%{http_code}' http://127.0.0.1:8000/tasks     # 期望 401 auth_required
curl -s -w '%{http_code}' http://127.0.0.1:8000/todos     # 期望 401
curl -s -w '%{http_code}' -H 'Authorization: Bearer 伪造串' http://127.0.0.1:8000/tasks   # 期望 401
```

同时：外网直连 8000 不通（第 2 条已覆盖）；Redis 不可达时闸机 fail-closed（把 `RUOYI_REDIS_URL` 改错重启后接口应 401 而非放行——可选深度验证）。
