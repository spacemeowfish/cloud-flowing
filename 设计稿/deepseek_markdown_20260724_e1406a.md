# 基于RK3588多端互联语音助手 —— 功能开发清单（MVP → 落地版）

**版本**：V1.0  
**更新日期**：2026年7月24日  
**说明**：本文档列出从零开发到可演示产品所需的所有具体功能模块，并按优先级（P0/P1/P2）和开发阶段排序。

---

## 一、系统底层与硬件适配层（基础中的基础）

| 序号 | 功能模块 | 具体开发内容 | 优先级 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 1.1 | Ubuntu系统裁剪与驱动适配 | 烧录Ubuntu 22.04，点亮MIPI-DSI屏，驱动GPIO、I2S音频Codec、PDM麦克风 | **P0** | 难点在设备树（DTS）配置，尤其PDM多通道合并 |
| 1.2 | 麦克风阵列多通道录音 | 实现4路PDM同时录音并合成PCM流，完成VAD（人声检测） | **P0** | 需确认`arecord`多通道支持，否则用ALSA底层API |
| 1.3 | 扬声器音频输出 | 驱动I2S功放，实现TTS（文字转语音）播报 | **P0** | 初期用`aplay` + Edge TTS / 离线Ekho |
| 1.4 | 散热风扇智能调速 | 根据芯片温度（读取`/sys/class/thermal/thermal_zone*/temp`）自动启停风扇 | **P1** | 避免满载烧毁，初期可常开风扇验证 |

## 二、语音交互闭环（能听、能懂、能说）

| 序号 | 功能模块 | 具体开发内容 | 优先级 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 2.1 | 离线唤醒词引擎 | 部署轻量级唤醒词模型（如Porcupine），实现“一喊就醒” | **P0** | 初期固定唤醒词（如“你好小智”），暂不绑定声纹 |
| 2.2 | 语音转文字（ASR） | 本地或云端ASR。**初期强烈推荐云端**（讯飞/阿里云） | **P0** | 云端识别准且快，本地PaddleSpeech效果待验证 |
| 2.3 | 本地1.5B模型推理 | 使用RKLLM-Toolkit部署Qwen2.5-1.5B（INT4量化） | **P0** | 技术底座，先跑通“输入文字→输出回复” |
| 2.4 | 意图分类器（路由层） | 判断用户指令归属：闹钟/备忘录 / PC操控 / 智能家居(礼让) / 闲聊（走云端） | **P0** | 初期用关键词匹配，后期可用本地Qwen做分类Prompt |
| 2.5 | 文字转语音（TTS） | 输出语音播报 | **P0** | 推荐Edge TTS（在线）或离线Ekho（断网可用） |
| 2.6 | 对话上下文管理 | 维护最近3轮对话历史，支持追问（如“改成明天下午”） | **P1** | 本地模型存不下长上下文，只存最近几句 |

## 四、PC端操控闭环（核心差异化功能）

| 序号 | 功能模块 | 具体开发内容 | 优先级 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 4.1 | PC端Agent服务程序 | 编写Python exe（Win）/ App（Mac），开机自启，后台常驻 | **P0** | 使用`pystray`做托盘图标 |
| 4.2 | 设备↔PC的局域网通信 | 建立Socket/WebSocket长连接，双向收发JSON指令，心跳检测（每5秒） | **P0** | 初期用TCP Socket最稳 |
| 4.3 | 文件操作指令 | Agent接收指令：①移动/复制/删除文件 ②获取文件列表 ③打包压缩 | **P0** | 使用Python `shutil` / `os` 实现 |
| 4.4 | 无头上传文件（生成链接） | 将文件上传至百度网盘/阿里云盘/自建NAS，返回公开链接 | **P1** | 初期可简化为“复制到桌面‘已发送’文件夹” |
| 4.5 | 模拟键鼠操作（进阶） | 模拟按键（Ctrl+S等）、打开微信→搜索联系人→粘贴发送 | **P2** | 使用`pyautogui`，易受分辨率影响，初期不建议 |
| 4.6 | 系统通知监听 | 监听Windows通知中心弹窗（微信/钉钉新消息），提取发送人和内容 | **P2** | Win API Hook难度较大，列为远期 |

## 八、关键实施建议

> ⚠️ **核心路线**：**不要一上来就做声纹（5.2）和模拟键鼠（4.5）**，这两个坑极深。  
> ✅ 先用一个**物理按键或拨码开关**模拟“主人/访客”身份，专注打通“语音→发文件→屏幕确认”这条主线。  
> ✅ 等这条流程跑得丝滑流畅、可对外演示后，再逐步填入高级功能。
