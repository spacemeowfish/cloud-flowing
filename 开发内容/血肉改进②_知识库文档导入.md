将此提示词完整复制给 Codex，作为开发任务。

## 开发提示词

### 目标
为本地知识库导入 5-8 份中文演示文档，使 `knowledge_query` 工具在演示时能检索到真实内容并返回带来源引用的答案。同时编写一个文档导入 CLI 命令，方便后续批量添加文档。不修改知识库工具的核心逻辑。

### 判断标准

1. 在 `demo_docs/` 目录下创建 5-8 份模拟企业内部文档（.txt 或 .md），内容覆盖产品信息、请假制度、报销标准、安全规范、设备手册等常见查询场景
2. 每份文档 300-800 字，包含明确的事实陈述，方便检索命中
3. 实现 `agent-platform import-docs <目录>` CLI 命令，扫描指定目录下的文档并导入知识库索引
4. 导入后，提问「产品保修期多久」能返回文档中对应的保修期信息，且附带来源文件名
5. 提问文档中不存在的信息（如「公司股价多少」）时返回「未找到相关信息」

### 证据要求

- 导入全部演示文档后，用 5 个不同的问题测试检索准确性
- 至少 3 个问题能命中文档中的精确事实并返回正确答案 + 来源
- 至少 1 个问题因为知识库无相关信息而正确拒绝回答
- `import-docs` 命令支持 `--force` 参数强制重建索引

### 权限边界

- 演示文档不允许包含真实个人信息、真实 API Key、真实内部数据
- 导入命令只索引配置白名单目录下的文件
- 不修改知识库的检索和问答逻辑（只添加数据 + 入口命令）

### 停止条件

- 5 份演示文档就位
- `agent-platform import-docs demo_docs` 命令可执行
- 3+ 个查询命中测试通过
- 1+ 个「无信息」拒绝测试通过
- `agent-platform demo` 中的默认任务（知识库查询）能返回实质性内容而非「未找到相关信息」

### 完成边界

新建文件：`demo_docs/` 目录下 5-8 份文档、`agent_platform/cli.py` 新增 `import-docs` 子命令、`README.md` 更新演示说明。不改动 `tools/knowledge_base_tool.py` 的核心逻辑。

## 代码审查提示词（质量）

检查项：
1. 导入命令是否处理了文件编码问题（UTF-8 BOM、GBK 编码的旧文档）
2. 重复导入同一份文档是否幂等（不产生重复索引条目）
3. 导入失败的文档是否有明确的错误信息（文件名 + 失败原因）
4. 文档内容是否在索引前经过了数据分级检查

---

## 代码审查提示词（性能）

检查项：
1. 批量导入时是否逐文件显示进度
2. 100 份文档的导入时间是否在可接受范围（< 30 秒）
3. 索引文件大小是否合理（不因重复导入无限增长）

---

## 代码审查提示词（复用性）

检查项：
1. 文档导入逻辑是否独立于 CLI 层（可通过 API 调用）
2. 是否支持后续扩展文档格式（只需注册新的 Parser）
3. 导入命令是否与知识库的具体存储实现解耦
