# 子 Agent 调度指南

> 每个模块的开发提示词已独立为 `prompts/` 目录下的文件，直接作为 subagent task 参数传入。
> 审查提示词在同一个文件内，模块开发完成后继续喂给审查子 Agent。

---

## 使用方式

每个文件是一个**自包含的任务**。复制文件内容，作为 `subagent(task="...", access="write")` 的 task 参数。

### 单个模块开发（示例）

```
subagent(
  task="[复制 prompts/F1_项目骨架与数据协议.md 中「开发提示词」段落的全部内容]",
  access="write",
  label="F1 项目骨架"
)
```

### 单个模块审查（示例，模块开发完成后）

```
subagent(
  task="[复制 prompts/F1_项目骨架与数据协议.md 中「代码审查提示词（质量）」段落 + 附上 F1 开发产出的代码]",
  access="read",
  label="F1 审查-质量"
)
```

## 上下文消耗估算

| 阶段 | 文件大小 | 单 Agent 上下文 |
|---|---|---|
| F1-F8 开发 | 1.4-2.0 KB/个 | 约 50-80 行提示词 |
| T1-T5 开发 | 0.9-1.0 KB/个 | 约 30-40 行提示词 |
| I1-I3 开发 | 0.9-1.1 KB/个 | 约 30-40 行提示词 |
| 审查 | 约 0.3 KB/个 | 约 15-20 行提示词 + 被审代码 |

单个 Agent 的上下文消耗极小，不会被提示词本身撑爆。
