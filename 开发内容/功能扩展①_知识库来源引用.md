# 功能扩展①：知识库来源引用（开发提示词 v2）

> 设计书要求：知识查询和摘要结果必须显示来源、更新时间和适用范围。
> 本任务只完善本地知识库的确定性来源元数据，不引入新的云端问答链路，不改变 Agent 编排。

---

## 可直接执行的开发任务

在 `D:\my new work\cloud flowing` 实现知识库查询的可追溯来源引用。先阅读现有 `KnowledgeBaseTool`、`SQLiteVectorStore`、相关测试和 `AgentCore` 的工具回执交付逻辑，再开始编辑。

### 目标

让 `knowledge_query` 的每个有检索依据的结果，返回由检索层确定性生成的 `sources`；每条来源包含文件名、可定位分块、脱敏原文片段、文档更新时间和适用范围。无命中时明确返回“未找到相关信息”和空来源列表，不编造内容。

### 当前架构事实

- `KnowledgeBaseTool` 当前为本地检索加抽取式短答，不把检索片段发送给 `cloud_adapter` 生成答案。
- 工具回执的 `output` 已由 `AgentCore` 原样写入任务结果；不要为透传 `sources` 修改 Agent Core。
- 向量检索已有文档文件名、分块位置、分块文本和分数；文档索引已有修改时间。来源字段必须从这些确定性数据或文档声明中产生。

### 结果契约

命中时工具回执的 `output` 至少为：

```json
{
  "answer": "根据《产品保修政策》第 3 个分块：保修期为 12 个月。",
  "sources": [
    {
      "file": "产品保修政策.md",
      "section": "分块 3",
      "snippet": "保修期自购买日起计算，为期 12 个月。",
      "updated_at": "2026-07-29T09:00:00+00:00",
      "scope": "售后与保修"
    }
  ]
}
```

规则：

1. `file` 只能是文件名，不能泄露绝对路径。
2. `section` 可使用可靠的章节标题；当前无法可靠提取标题时，必须使用可复现的“分块 N”，不得伪称“第 N 段”。
3. `snippet` 从已脱敏的命中文本截取，去除首尾空白，长度不超过 100 个字符。
4. `updated_at` 取索引文档的 `mtime` 并序列化为带时区 ISO 8601；不可使用当前查询时间代替。
5. `scope` 仅可取文档明确声明的适用范围。首版可从 Markdown front matter 的 `scope` 或文档首个明确的“适用范围”字段读取；没有声明时返回 `"未声明"`，不得推断。
6. `answer` 可以对最佳命中做短摘录并增加确定性来源前缀，但不得声称命中内容未表达的事实。
7. 多个检索命中必须保留全部 `sources`，按检索排序输出；回答可以只摘录最佳命中。
8. 无命中时固定返回：`{"answer":"未找到相关信息","sources":[]}`。来源覆盖率只统计有检索依据的回答。

### 允许修改

- `agent_platform/tools/knowledge_base_tool.py`
- `agent_platform/tools/vector_store.py`
- 与本功能直接相关的模型、测试和评测文件

不要修改：

- `AgentCore` 的状态机、Schema 校验、策略引擎和路由逻辑。
- `cloud_adapter.py`。它是意图提取适配器，不是知识库答案生成器。
- 知识库授权根目录、数据分级或现有脱敏规则。

### 实现要求

1. 在检索数据结构中补齐生成来源所需的文档修改时间；优先扩展存储层查询，不在工具层重复扫描文件系统。
2. 新增一个小型、纯函数的范围提取逻辑，并为“有 scope / 无 scope / 非 Markdown 文档”分别测试。
3. 来源数据必须在工具层生成。前端自然语言展示、模型生成引用或模糊相似度不作为正确性依据。
4. 保持工具的本地执行、超时、数据分级和回执结构；不增加网络请求或模型调用。
5. 不把完整命中文本、查询原文或绝对路径写入新增日志；复用现有脱敏文本。

### 验收与证据

新增覆盖以下行为的自动化测试：

1. 单文档命中：字段完整、文件名无路径、片段不超过 100 字。
2. 多文档命中：所有命中均返回，顺序稳定。
3. 命中片段含敏感内容：片段仍来自脱敏文本。
4. 文档修改后重新索引：`updated_at` 更新。
5. 有声明和无声明的 `scope` 分别返回声明值与 `未声明`。
6. 无命中：精确返回“未找到相关信息”和空数组。
7. Agent 集成：任务最终 `result.output.sources` 与工具回执一致。

运行现有全量 `pytest`，以当前基线 `206` 项为参照，不得引入回归；新增测试必须全部通过。运行既有 `knowledge_query` 评测用例，意图与工具选择不得退化。

### 停止条件

只有在来源字段来自确定性检索数据、无命中不编造、上述测试和全量回归均通过时完成。若现有索引无法可靠提供章节或范围，只交付“分块 N / 未声明”的诚实结果，不用猜测填充。

### 交付

交付修改文件列表、测试命令及结果，以及一条命中和一条无命中的脱敏回执示例。
