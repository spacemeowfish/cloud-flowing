# ADR 0007：轻量开发者模式与双界面

- 状态：采纳
- 日期：2026-08-16

## 背景

开发板演示需要让普通用户直接完成任务，同时保留现有完整控制台用于开发调试。浏览器还需要支持受信任局域网内的电脑预览，但当前阶段不需要完整商业认证、用户后台或 RBAC。

## 决策

根路径 `/` 提供免登录普通任务页，只呈现通用任务输入、任务生命周期、确认、取消、结果和错误。`/developer` 提供现有完整控制台，并由本地 `DEVELOPER_PASSWORD` 解锁。

服务端使用常量时间比较校验密码，成功后生成随机内存令牌并通过 HttpOnly、SameSite Cookie 保存。浏览器任务会话同样由服务端 Cookie 生成，不再信任 `X-Agent-Role` 或 `X-Session-Id`。开发者会话不持久化，服务重启后必须重新登录。

管理接口、完整能力信息、任务审计、最近日志和 Swagger/OpenAPI 只允许开发者访问。最近日志只保留内存中最多约 200 条脱敏记录，并由页面手动刷新。

服务默认监听 `127.0.0.1`。只有显式配置非回环 `AGENT_HOST` 且同时配置 `DEVELOPER_PASSWORD` 时，才允许在受信任开发网络中进行板端局域网预览。

## 后果

- 普通用户无需账号即可使用自己的任务会话，开发者入口保持低干扰。
- 不引入用户表、角色表、密码哈希库、失败锁定、自动降权、登录审计、CSRF 框架或持久会话数据库。
- 明文环境变量密码可以满足当前开发演示，但必须位于 Git 忽略范围，且不得进入日志、前端或 API 响应。
- 局域网预览不是生产级部署；公网暴露仍不在范围内。
- TTS、ASR、唤醒词、真实模型验收和 RK3588 性能验收保持独立。
