# ADR-0002：采用预路由与单意图参数抽取

- 状态：已采纳
- 日期：2026-08-02

## 背景

Qwen2.5:3b 在固定 60 条真实评测中出现明显的跨工具字段串扰，并在提醒、待办、日程和会议文件边界上误选意图。原实现让小模型在一次生成中同时选择七种意图并面对七套参数字段。

## 选项

1. 继续扩大全量单次 Prompt 和示例。
2. 对所有请求固定调用两次模型：先分类，再按单一意图抽参。
3. 高置信锚点由确定性预路由选择意图；其他请求模型分类；随后统一按单一意图抽参。

## 决定

采用选项 3。预路由只返回意图，不拥有参数；参数始终由模型在所选意图的接受 Schema 下生成。有效 JSON 若违反当前阶段 Schema，可携带精简错误和原输出重试一次，重试不能改变目标意图或 Schema。

## 后果

- 明确请求通常保持一次模型调用；模糊请求需要两次调用。
- 模型无法在参数阶段输出另一个工具的字段，跨工具字段错误会在 Adapter/Gateway 边界被拒绝。
- 预路由规则成为需要回归测试的产品语义，特别是相对时间优先提醒、会议路径优先会议处理。
- 评测必须调用与生产相同的理解入口，并记录路由来源和模型调用次数。

## 验证

- 预路由、分类回退、单意图 Schema 和受限修复单元测试。
- Agent Core 四类文本操作及确认流集成测试。
- 同一固定 60 条 Mock、RKLLM 协议模拟和真实 Qwen A/B。
