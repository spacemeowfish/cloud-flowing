# ADR 0005：同进程监督式桌面重启

- 状态：采纳
- 日期：2026-08-12

## 背景

设置页需要修改项目 `.env` 后自动重启服务，并在新配置无法启动时恢复旧配置。普通 `serve` 由 Uvicorn 自行持有生命周期，无法可靠地从请求处理函数中完成重启和回滚。

## 决策

新增 `agent-platform desktop`。该命令在一个监督循环中逐次创建 `Settings`、FastAPI 应用和 `uvicorn.Server`。管理 API 保存设置后向注入的重启控制器发出请求，控制器在响应返回后设置 `server.should_exit`；服务完成 lifespan 关闭后，监督循环清除配置缓存并用新设置重新启动。

设置写入前创建本地备份并使用 `os.replace` 原子替换。若下一轮配置加载或应用启动失败，监督器恢复本次备份并再次启动旧配置。重启状态在监督器对象中跨应用实例保留，供新服务返回。

## 后果

- `serve` 仍适合开发和测试，但保存设置后只返回“需要手动重启”。
- `desktop` 不需要额外子进程或公开关机端点，SQLite、提醒和日程可通过 FastAPI lifespan 正常关闭。
- 浏览器只在首轮服务就绪后打开一次；重启时页面轮询恢复。
