# ADR 0006：后端内存按键说话

- 状态：采纳
- 日期：2026-08-12

## 背景

桌面试用需要本地麦克风输入和 Faster-Whisper 转写，但本轮不引入浏览器音频上传、Vosk、唤醒词或会议录音归档。

## 决策

FastAPI 后端通过 `sounddevice.RawInputStream` 采集 16 kHz、单声道、PCM16。全局录音服务以互斥锁保证单录音，音频块保存在有上限的内存缓冲区。停止后将 PCM 转为 `float32` 并交给懒加载的 Faster-Whisper small 模型；无论成功、取消、异常或超时，均清空 PCM 引用。

默认 CPU INT8、8 线程、单工作线程、beam size 3、VAD 开启、最长 30 秒。转写结果经繁体转简体和空白归一后返回，仅由页面回填通用任务输入框，不自动提交。

## 后果

- 原始音频不写入文件、数据库或审计日志。
- 音频设备和模型依赖为可选依赖；缺失时文本 Agent 仍可启动并返回明确状态。
- 录音会占用服务端机器的默认或指定麦克风，因此该能力只面向本机桌面运行。
