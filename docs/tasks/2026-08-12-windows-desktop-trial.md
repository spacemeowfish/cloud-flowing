# Windows 桌面试用功能

- 状态：完成，等待用户实际体验
- 日期：2026-08-12
- 分支：`codex/desktop-v003`
- 基线：`main` / `ebc208f1a84c6b383bd7b15218fbb8d792ae559a`

## 目标

在不制作安装包的前提下，交付可在 Windows x64 本机直接体验的设置、受控重启、文件打开、Toast、按键说话、Faster-Whisper、Ollama 模型切换和 ZipVoice 配置能力。

## 非目标

- 不做安装包、托盘、开机自启动。
- 不做会议录音转写、唤醒词、Vosk 常驻监听或 RK3588 音频链路。
- 不把 Faster-Whisper 或 ZipVoice 模型复制进仓库。

## 架构不变量

- 页面不读取、返回或覆盖 API 密钥；不在可编辑设置中出现密钥字段。
- 外部进程环境变量优先于项目 `.env`，对应字段在页面只读。
- `.env` 在同目录原子替换，写前保留最近 5 份备份；新配置启动失败时恢复旧文件。
- `serve` 保持开发模式；只有 `desktop` 命令提供浏览器打开和受控自动重启。
- 同一时刻只允许一个录音；PCM 只驻留内存，停止转写、取消、超时或失败后均释放。
- Whisper 文本只回填输入框，不自动提交 Agent 任务；录音前停止浏览器中的 TTS 播放。
- 文件打开继续受授权目录和显式候选确认保护；系统回执只声明 Shell 已接受请求，不伪造窗口可见性。

## 验收条件

1. 管理 API 完成设置读取、验证、原子更新、五份备份、重启状态、知识重建和测试通知。
2. `agent-platform desktop` 能启动 Uvicorn、打开操作台、应用新配置并在失败时回滚。
3. 语音 API 区分无麦克风、设备不可用、过短、静音、模型缺失、服务忙和转写超时。
4. 操作台设置页及按键说话在 1440x900 和 390x844 无横向溢出或重叠。
5. 自动化覆盖配置、重启、密钥保护、录音状态机、PCM 释放、ASR 假实现、会话隔离和前端语法。
6. Mock、三个 Ollama 模型、ASR、TTS、Toast 和文件打开结果分别记录，不用 Mock 结果替代真实模型或 Windows 验收。
